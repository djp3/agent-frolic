Each repository has a timer of its own, so the app asks GitHub less.

- **A timer for each repository.** One GitHub sends webhooks for is read every half hour, to catch a delivery that never came. One it sends none for is read every five minutes, as before. Any read starts that repository's timer again, and `u` still reads them all now.
- **The two bars are on each repository's line**, no longer at the top. The upper one empties until that repository is next read, the lower one since GitHub last sent a webhook about it.
- **Back to five minutes when a webhook cannot be relied on**: while the last read failed, while GitHub is still working out whether a pull request can merge, and while the tunnel does not lead back to the app. After the Mac has slept, the repositories with webhooks are read at once.
- **A repository with nothing open takes one line.** Its own line says "0 open", in a narrow window too, so the line under it saying "nothing is open" is gone.
