The board keeps up with a pull request while it is being reviewed, and shows Copilot at work.

- **A change to a pull request shows within seconds.** When GitHub says which pull request changed (a review asked for or given, a comment, a check, new commits), the app now reads that one alone. Before, it read the whole repository again, which with ten repositories shown it could afford only every twelve minutes or so.
- **Copilot's mark turns while it reviews.** From the moment it is asked until its review arrives, Copilot has the turning dots of an agent at work: in the review column, where the pull request waits on it, on its card, and in the drawer, which says "reviewing". A person who was asked keeps `◔`.
- **No more of GitHub's allowance is used.** The reads GitHub's messages ask for are still held to half of what GitHub allows the token in an hour, shared among the repositories shown. Each repository's timer and `u` still read the whole of it, as before.
