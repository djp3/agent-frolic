Each of your agents has a number of its own, and an agent named for a pull request that is not open is shown.

- **Each person's agents are numbered across the whole board.** Before, agents were numbered on each pull request alone, so every agent with a pull request to itself was "agent 01". Now yours run from agent 01 to however many you have on the board, and so do each teammate's. "you · answer agent 07" means one session.
- **No number is ever missing.** When an agent leaves the board, the one with the highest number takes the number it left, and every other agent keeps its own. A new agent takes the next number, and a session you rename keeps its number.
- **An agent named for a pull request that is not open is shown.** An agent named ahead of the pull request it is about to open, or still named for one that has merged or closed, was drawn nowhere. It now has a line under its repository, which says which pull request is not open (`#98 is not open`). It moves onto the pull request once that is open.
- **`C` copies the whole rename command.** `c` copies the name that puts an agent on the selected pull request. `C` now copies `/rename` and the name together, ready to paste at the agent's prompt.
- **The ticker asks for a rename only when one is needed.** When you open a pull request and an agent of yours is on it already, named ahead of it, the ticker says only that you opened it.
