The first release of agent-frolic as a Mac app.

- **The board** shows the open pull requests of the repositories you choose: who each one waits on, its reviews, checks and progress, and how long it has been quiet.
- **Live changes** arrive through GitHub webhooks once you set them up; without them the app reads GitHub again on a timer.
- **Your GitHub token** and the app's other secrets are kept in the macOS Keychain, never in a file.
- **Updates** are offered in a window like this one, with what is new in each release. Help > Release Notes opens the notes of every release.
