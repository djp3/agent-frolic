An agent at work is easier to see, and one that waits on a command it started is told apart.

- **An agent at work has a green wheel.** The mark before its name is now a wheel that goes round once a second, in green, and a green light runs through the agent's name and the word "working". Before, the mark was three small dots in the same ink as the name, and easy to miss.
- **An agent that waits on a command has the same in white.** When an agent is idle while a command it started is still running, a test run or a watch on the checks, its wheel and its light are white and its state says "command". Before, it looked like any other idle agent.
- **A command is not counted as work.** A pull request whose agent only waits on a command stays on your list when the next move is yours, with the yellow dot. A command can run for hours, and would otherwise read as work for as long.
- **Copilot has the green wheel while it reviews.** Where a pull request waits on it, and on its card, a green light runs through its name as well.
